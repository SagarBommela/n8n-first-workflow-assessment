# Topic 8: Webhook Trigger

## Overview

This project demonstrates how to use the Webhook Trigger node in n8n to receive incoming HTTP POST requests, capture request body data, and transform it into a clean output structure using the Edit Fields node.

The workflow receives customer contact information and maps the incoming data to three clearly named fields.

**Workflow Name:** Topic 8 Webhook Trigger Workflow

## Learning Objectives

- Understand how webhook-triggered workflows work.
- Configure a Webhook node to accept HTTP POST requests.
- Understand the difference between Test and Production Webhook URLs.
- Send a test request using `curl`.
- Inspect incoming request body data.
- Map nested JSON properties using n8n expressions.
- Remove unnecessary input fields from the final output.

## Workflow Design

The workflow contains two nodes:

1. **Webhook** – Receives incoming HTTP POST requests.
2. **Process Webhook Data** – Extracts the customer name, email, and message into a clean output structure.

Workflow structure:

```text
External HTTP POST Request
            |
            v
         Webhook
            |
            v
  Process Webhook Data
            |
            v
      Clean JSON Output
```

## Webhook Configuration

Configure the Webhook node as follows:

| Setting | Value |
|---|---|
| Node name | Webhook |
| HTTP Method | POST |
| Path | `contact-form` |
| Test URL | Use the URL generated by your n8n instance |
| Production URL | Use after publishing or activating the workflow |

### Test URL

The Test URL is used during development. In the editor, select the test-listening option before sending a request. The webhook listens for an incoming request for a limited period, commonly up to 120 seconds.

Example format:

```text
https://your-instance.app.n8n.cloud/webhook-test/contact-form
```

Use the actual Test URL displayed by your n8n instance.

### Production URL

The Production URL is used for requests sent to a published or active workflow.

Example format:

```text
https://your-instance.app.n8n.cloud/webhook/contact-form
```

Use the actual Production URL displayed by n8n. Production requests do not necessarily appear as live editor test output; inspect the workflow's execution history when necessary.

## Test Request

The following example sends customer contact information to the Test Webhook URL.

Replace `YOUR_TEST_WEBHOOK_URL` with the exact Test URL copied from your Webhook node.

### curl command

```bash
curl -X POST "YOUR_TEST_WEBHOOK_URL" \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice Smith","email":"alice@example.com","message":"Hello from webhook!"}'
```

For Windows Command Prompt, the equivalent command is:

```cmd
curl -X POST "YOUR_TEST_WEBHOOK_URL" -H "Content-Type: application/json" -d "{\"name\":\"Alice Smith\",\"email\":\"alice@example.com\",\"message\":\"Hello from webhook!\"}"
```

Keep the JSON valid and ensure there are no unintended spaces inside the email value.

## Incoming Request Data

The Webhook node receives the following JSON body:

```json
{
  "name": "Alice Smith",
  "email": "alice@example.com",
  "message": "Hello from webhook!"
}
```

In the Webhook node's output, the body is typically accessible through `$json.body`.

The exact output structure may include additional information, such as headers, query parameters, and request metadata.

## Process Webhook Data Configuration

Rename the Edit Fields node to **Process Webhook Data**.

Disable **Include Other Input Fields** so that the node outputs only the fields defined in the mapping configuration.

Configure the following String fields:

| Output Field | Expression | Expected Value |
|---|---|---|
| `customerName` | `{{ $json.body.name }}` | `Alice Smith` |
| `customerEmail` | `{{ $json.body.email }}` | `alice@example.com` |
| `customerMessage` | `{{ $json.body.message }}` | `Hello from webhook!` |

These expressions extract the three properties from the incoming request body.

## Expected Output

After sending the test request and executing both nodes, the final output should look like this:

```json
[
  {
    "customerName": "Alice Smith",
    "customerEmail": "alice@example.com",
    "customerMessage": "Hello from webhook!"
  }
]
```


## Implementation Steps

1. Create a workflow named `Topic 8 Webhook Trigger Workflow`.
2. Add a Webhook node.
3. Set the HTTP method to POST and the path to `contact-form`.
4. Copy the Test URL from the Webhook node.
5. Click the test-listening button.
6. Send the HTTP POST request using `curl`.
7. Inspect the Webhook node output and verify the request body.
8. Add an Edit Fields node and rename it `Process Webhook Data`.
9. Disable Include Other Input Fields.
10. Map the three customer fields using expressions.
11. Test the workflow and inspect the final JSON output.
12. Save the workflow and export the actual workflow JSO
